# 보강 우선순위

현재 코드 기준 점검 결과입니다. 완료되지 않은 항목을 이미 해결한 기능처럼 안내하지 않습니다.

## P1 — 배포 전 우선

1. **캐시 위치와 보관 정책**
   - 0.2.0에서 원본 복사본·PDF·로그·WebView2 데이터를 사용자 LocalAppData로 분리했습니다.
   - 앱 폴더 쓰기 권한 문제를 줄였으며, 민감 문서 잔존 문제는 남아 있습니다.
   - 자동 만료·지우기·저장 위치 UI 및 실패 작업 정리를 추가해야 합니다.

2. **신규 PC 설치 재현성**
   - CAD용 Python 및 패키지, .NET, WebView2, Windows 한글 글꼴에 의존합니다.
   - 엔진 상태를 한 화면에서 진단하고, 서명된 설치/업데이트 패키지와 깨끗한 Windows VM 검증이 필요합니다.
   - 공개 준비 과정에서 버전/해시 고정 다운로드 스크립트와 빌드 CI를 추가했습니다. 0.2.0에는 .NET/Python 포함 로컬 시험 설치판을 추가했습니다. 깨끗한 PC와 코드 서명 검증은 남아 있습니다.

3. **실제 문서 호환성 회귀 묶음**
   - 현재 업무용 샘플 6개를 통과한 결과를 모든 문서 정확도로 확대할 수 없습니다.
   - 비식별 HWPX/PPTX, 복잡한 표·도형·수식·다중 시트, 암호/손상/대용량 샘플과 페이지·금액·누락 객체 기준을 만들어야 합니다.
   - XLS 병합 셀 보정에는 숨김 열/가로 페이지 분할/복합 병합 등의 추가 합성 회귀 검사가 필요합니다.

4. **전체 배포물 라이선스·공급망 점검**
   - LibreDWG 실행 파일/DLL, office2pdf의 글꼴·의존성 등은 TOPDF 자체 MIT 라이선스와 별개입니다.
   - 바이너리 공개 릴리스 전에 SBOM, 대응 소스, 고지, 글꼴 재배포 조건과 서명·해시 확인을 마무리해야 합니다.
   - 이번 공개 저장소에서는 외부 바이너리와 고객 문서를 제외했습니다.

## P2 — 안정성과 사용성

5. **CAD 출력 옵션**: A3 전체 맞춤에서 레이아웃·용지·축척·색상·선 굵기 선택으로 확장. XREF 누락과 글꼴 대체를 결과 화면에 표시.
6. **자원 제한과 종료 처리**: 엔진별 메모리/쪽수 제한, 워커 충돌 복구, 설치형 한글 COM의 취소 시 잔존 프로세스 처리 검증.
7. **오류 안내 개선**: 현재 일부 실패는 로그 경로만 보여줍니다. 엔진 없음·암호·지원 객체·시간 초과를 구분하고 재시도 방법을 제시해야 합니다.
8. **비동기 파일 저장**: 일괄 저장 중 진행률·취소, 큰 파일과 긴 경로·네트워크 폴더 시험을 보완해야 합니다.
9. **창/작업 관리**: 탐색기에서 여러 번 열 때 단일 인스턴스에 작업 전달, 중복 변환 캐시, 목록 삭제·작업 우선순위.

## 공개 준비에서 완료한 사항

- 현재 지원을 한글·워드·엑셀·DWG·DXF 5가지로 정리하고 PDF 바로 보기를 별도 안내
- PDF 글자와 아래 화살표의 로고 및 Windows 아이콘 적용
- 원본 문서·로그·캐시·변환 결과·외부 엔진 바이너리를 Git에서 제외
- 고정 엔진 다운로드, XLS 재현 빌드, Windows 빌드/파일 저장 CI, 기여·보안 안내 추가

## 0.2.0에서 보강한 사항

- 파일 추가 시 자동 변환, 동작 중 추가 파일 대기열 처리
- 작은 문서 탭, 중복 열기 방지, 탭 닫기 및 인접 문서 복귀
- 실제 6개 문서 17쪽의 기존 PDF 결과 비교와 합성 문서/오류 입력 회귀 검사
- 계산 결과 없는 XLSX 수식의 빈칸 출력 방지
- 사용자 데이터 경로 분리, .NET/Python 포함 설치판 제작 스크립트
