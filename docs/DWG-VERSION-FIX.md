# DWG 세대 유지 변환 (0.3.4)

기존 코드는 모든 DWG를 LibreDWG 0.14의 `--as r2018`로 출력했습니다. 확인한 AC1015(AutoCAD 2000) 실사용 도면에서는 종료 코드 0이지만 모델과 모든 블록이 빈 DXF가 생성됐습니다. 같은 파일을 `--as r2000`으로 출력하면 모델 공간의 1,111개 객체와 블록 내용이 유지됩니다.

DWG의 6바이트 서명을 읽어 해당 세대의 DXF를 지정하도록 수정했습니다. AC1015→r2000, AC1018→r2004, AC1021→r2007, AC1024→r2010, AC1027→r2013, AC1032→r2018이며, 오래된 AC1009는 r12, AC1012/AC1014는 지원되는 r14를 사용합니다. 알 수 없는 서명은 기존 r2018 경로를 유지합니다. 실패했다고 최신 도면을 무조건 옛 버전으로 내려 저장하지 않습니다.

변환기 종료 코드·출력 파일 존재뿐 아니라 출력 가능한 레이아웃의 객체 존재를 검사합니다. 빈 결과는 PDF 저장 전에 거부하며, 선택한 원본/DXF 세대와 종료 코드를 `dwg-converter.json`에 남깁니다. 성공 메타데이터에는 레이아웃별 객체 수를 포함합니다. 실패 사유는 앱이 읽는 UTF-8 오류 파일에도 기록합니다.

## 실제 파일 검증

- 수정 전 r2018: 모델·배치·블록 모두 빈 도면, PDF 변환 실패.
- 수정 후 r2000: 모델 공간 1,111개 객체, A3 가로 전체 맞춤 PDF 1쪽 생성.
- 독립 `dwgread -O JSON` 결과와 DXF의 전체 객체 수 비교: LWPOLYLINE 439, TEXT 406, POINT 308, INSERT 104, LINE 69, SOLID 36, HATCH 25, CIRCLE 14, ARC 1 및 BLOCK/ENDBLK 각각 22개가 일치.
- 원본 해시 보존과 실제 앱의 자동 변환·내장 PDF 미리보기를 확인합니다. 사용자 도면과 검증 산출물은 로컬 artifacts에만 보존합니다.

이는 모든 DWG에 대한 완전한 CAD 출력 보증이 아닙니다. 기존의 검정/흰색 A3 맞춤 미리보기를 유지하며, SHX/CTB/STB, 외부 참조, 프록시·3D, 정밀 축척·인쇄 품질은 별도로 검토해야 합니다. 최신 세대 및 다른 객체 조합은 추가 실제 문서 검증 대상입니다.
