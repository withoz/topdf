# 0.3.12 그리기 표시와 겹친 객체 선택

2026-11-10. 이전 설치 ZIP 0.3.11은 유지하며 이 변경은 별도 수정 실행판에서 검증합니다.

- 그리기 도구/제스처에서는 파란 선택 테두리와 조절점을 숨깁니다. 선택 또는 본문 도구의 선택 항목에는 다시 표시합니다.
- 도형 전체의 투명 사각 Border가 마우스를 가로채지 않게 하고, 캔버스 PreviewMouseLeftButtonDown에서 모델의 실제 모양으로 판정합니다.
- 선·화살표·자유곡선은 실제 선/화살촉, 빈 사각형·타원은 외곽선 가까이를 선택합니다. 화면상 4DIP의 여유를 줘 확대율이 달라도 클릭 허용 폭을 유지합니다.
- 채운 도형·메모·도장·추가 글자는 내부도 선택합니다. 겹친 후보는 앞쪽부터 판정하고 Alt+클릭으로 뒤쪽 후보를 순환합니다.
- 메모 입력창·본문 입력창·끝점/크기 조절점의 입력은 보호합니다. Alt로 메모 입력창 아래의 다른 객체를 고를 수 있습니다.
- Ctrl/Shift 다중 선택, 영역 선택, 이동·삭제·되돌리기·끝점·저장 동작은 유지합니다.

주요 파일: PdfEditorView.HitTesting.cs, Drawing.cs, Ribbon.cs, xaml.cs와 XAML의 캔버스 이벤트. DrawingUiTest에 그리는 중/도구 전환의 장식 표시, 빈 도형 통과, 화살표의 빈 영역, 채운 도형/Alt 순환, 회전, 실제 항목 선택 처리와 조절점 회귀 검사를 추가했습니다.

원본 PDF에 이미 합쳐진 임의 도형을 분해하지는 않습니다. 이 앱에서 추가한 편집 항목을 대상으로 하며 계속 편집할 문서는 .topdf도 저장합니다. 영역 선택은 기존과 같이 객체의 회전 경계 상자와의 교차를 기준으로 합니다.
