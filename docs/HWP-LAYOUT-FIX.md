# HWP 머리글·꼬리글·바탕쪽 보정 (0.3.3)

현재 Windows 앱은 upstream rhwp 0.8.7에 TOPDF의 로컬 패치를 적용한 `0.8.7-topdf.1`을 사용합니다. 별도로 설치한 한글 프로그램을 변환에 호출하지 않습니다. 문서별 이름·페이지 번호·좌표 상수나 기준 PDF를 변환 로직에 넣지 않습니다.

## 수정 범위와 근거

- 머리글·꼬리글 안에서 두 축이 PAPER/PAGE 기준인 부동 표는 물리 용지 원점 대신 해당 영역의 원점·크기를 사용합니다. 기존 그림 배치의 영역 규칙과 맞추며 일반 본문 표와 글자처럼 취급하는 표는 유지합니다.
- 글 뒤/앞에 놓인 절대 위치 표는 호스트 줄의 흐름 높이를 차지하지 않습니다. 저장된 줄 높이·영역 높이와 TOP/CENTER/BOTTOM 정렬을 이용해 표와 호스트 문장에 같은 영역 시작점을 적용합니다. 그림·도형을 포함하는 기존 별도 경로는 유지합니다.
- 부동 표 옆의 호스트 문장을 별도로 그립니다. 표 안의 쪽 번호와 호스트 문장의 구역명이 함께 표시됩니다. 인라인 표의 문장은 이 경로로 중복 출력하지 않습니다.
- 다음 구역에 로컬 바탕쪽이 없어도 이전 홀수/짝수 바탕쪽을 이어받습니다. 첫 쪽 바탕쪽 감추기와 로컬 바탕쪽 우선순위는 기존 규칙을 사용합니다.

독립 기준은 같은 HWP를 한글 프로그램에서 PDF로 저장한 35쪽 결과입니다. 원본 HWP를 수정하지 않았으며 로컬 검토 폴더에 입력 해시·기준 PDF·수정 전후 PDF·영역별 좌표와 비교 PNG를 보존했습니다. 고객 문서와 검토 산출물은 저장소에 올리지 않습니다.

## 확인 결과

| 항목 | 수정 전 | 수정 후 |
|---|---|---|
| 전체 쪽수 | 35쪽 | 기준과 같은 35쪽 |
| 머리글 23곳 | 약 25mm 왼쪽·20mm 위로 밀려 잘림 | 잘림 없음, 시작 위치 최대 차이 X 0.032mm / Y 0.019mm |
| 꼬리글 구역명 23곳 | 누락 | 모두 표시, 시작 위치 최대 차이 X 0.336mm / Y 0.283mm |
| 쪽 번호 23곳 | 약 25mm 왼쪽 이동 | 시작 위치 최대 차이 X 0.306mm / Y 0.282mm |
| 바탕쪽이 이어지는 두 쪽 | 배경 누락 | 배경 이미지·선 복구 |

수정 전후 72dpi 본문 영역(상단 95pt~하단 75pt 제외)을 비교해, 배경 복구가 의도된 두 쪽을 제외한 33쪽의 픽셀이 동일함을 확인했습니다. 이는 원본 전체의 완전한 시각 일치를 뜻하지 않습니다. 글꼴 폭·특수 기호와 다른 문서의 전체 조판은 별도 검수가 필요합니다.

이 검증은 TOPDF가 쓰는 Windows Native CLI의 SVG→PDF 경로에 한정됩니다. WASM과 upstream의 전체 시각 회귀 게이트를 통과했다는 주장은 하지 않으며 upstream PR·공식 릴리스로 제출한 패치가 아닙니다.

## 빌드와 배포

`scripts/rhwp-layout.lock.json`이 upstream 태그·커밋·패치 SHA-256을 고정합니다. `scripts/Build-RhwpEngine.ps1`은 별도 소스 폴더에 패치를 적용하고, upstream이 제공하는 최적화 `release-test` 프로필로 CLI를 빌드합니다. 이 프로필 이름은 테스트용 코드를 실행 파일에 넣는다는 뜻이 아니며, LTO를 끄고 코드 생성 단위를 늘려 빌드 시간을 줄입니다.

```powershell
./scripts/Build-RhwpEngine.ps1
# VS Redist 탐지가 안 되면 합법적으로 설치된 x64 CRT 경로를 지정합니다.
./scripts/Build-RhwpEngine.ps1 -CrtDirectory 'C:\path\to\Microsoft.VC145.CRT'
```

개발 PC에는 Git, Rust toolchain 및 MSVC 빌드 도구가 필요합니다. 설치 사용자에게는 컴파일 도구나 한글 설치가 필요 없습니다. 서명을 확인한 Microsoft `vcruntime140.dll`을 엔진 옆에 포함합니다. 설치판 빌드 시 엔진의 패치·바이너리 해시와 런타임 포함 여부를 확인합니다. upstream MIT 고지·패치·빌드 메타데이터도 함께 배포합니다.

## 로컬 재검사

```powershell
python tests/HwpLayout/compare.py --before old.pdf --after new.pdf --reference hancom.pdf --output artifacts/hwp-comparison
```

비교 도구는 반복 머리글, 하단 구역명·쪽 번호의 존재·잘림·좌표를 검사하고 대표 쪽 및 전체 쪽 축소 이미지를 만듭니다. 수치 검사와 실제 PNG 확인을 함께 수행하며 측정값을 원본과의 완전 일치 보증으로 사용하지 않습니다.
