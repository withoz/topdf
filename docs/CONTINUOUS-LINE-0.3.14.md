# 연속선 그리기 — 0.3.14

- 선 도구에서 시작점을 클릭한 뒤 다음 점을 차례대로 클릭합니다.
- 각 클릭이 이전 끝점부터 새 점까지의 선 한 개를 확정합니다. 마우스를 놓아도 연속 입력을 유지합니다.
- Shift를 누르면 수평 또는 수직으로 제한합니다.
- Enter 또는 우클릭은 연속 입력만 끝냅니다. 다시 클릭하면 새 시작점으로 그립니다.
- Esc는 미확정 미리보기를 없애고 선택 도구로 돌아갑니다.
- Ctrl+Z는 연속 입력을 끝내고 마지막으로 확정한 구간을 취소합니다. Ctrl+Y로 다시 실행합니다.
- 점만 반복 클릭하거나 6 화면 DIP보다 짧게 클릭하면 선을 생성하지 않습니다.
- 미리보기 선은 편집 모델에 포함하지 않습니다. 저장, 페이지 이동, 도구 전환 시 폐기합니다.
- 확정된 선은 각각 선택·끝점 수정·다중 선택·삭제할 수 있습니다. 기존 화살표와 도형은 드래그 방식입니다.

검증: CommandsUiTest의 연속선/명령 검사와 DrawingUiTest의 기존 도형·그룹·편집 파일·PDF 내보내기 검사.
실행판: artifacts/continuous-line/Topdf.exe. 설치판은 별도 빌드가 필요합니다.

## 기본 선종류 구현

펜 설정 팝업에 실선·점선·파선·일점쇄선·이점쇄선을 실제 패턴 견본과 함께 표시합니다. 선택한 도형은 즉시 변경되며 다중 선택에도 적용합니다. 화면, 연속선 미리보기, 편집 파일, PDF 벡터 저장에 같은 두께 비례 패턴을 사용합니다. 기존 dashed=true 편집 파일은 파선으로 읽습니다. 각 변경은 실행 취소할 수 있습니다.

## 우클릭 메뉴 확장 — 0.3.15에서 구현 완료

1. 객체 위 우클릭: 현재 선택 그룹 안이면 그룹을 유지하고, 다른 객체이면 해당 객체를 선택합니다. 색상·선종류·두께와 복사·복제·삭제를 제공합니다.
2. 색상: 작은 원형 팔레트, 현재 색 표시, 기본 주황색과 최근 사용 색을 제공합니다. 한 번 클릭하면 즉시 적용합니다.
3. 선종류: 실선·점선·파선·일점쇄선·이점쇄선을 실제 견본으로 표시합니다. 두께는 1·2·4·8pt와 세부 설정을 제공합니다.
4. 여러 객체: 그룹 전체에 한 번 적용하며 Ctrl+Z 한 번으로 복원합니다. 서로 다른 속성은 혼합 상태로 표시합니다.
5. 빈 공간: 선택을 해제하고 다음 도형의 기본 색상·선종류·두께를 설정합니다. 기존 객체는 변경하지 않습니다.
6. 연속선 중 첫 우클릭은 입력 종료만 수행합니다. 다음 우클릭부터 메뉴를 엽니다. 메모 입력 상자는 Windows 기본 글자 편집 메뉴를 유지합니다.
7. 겹친 객체: 현재 선택 유지와 아래 객체 선택 기능을 제공하며, 선택 프레임·도구 전환·저장·재열기에도 속성이 유지되는지 검사합니다.

완료한 구현 순서: 우클릭 대상/선택 처리 → 색상·선종류·두께 → 다중 선택 및 Undo → 키보드·겹침·저장 회귀 검사. 기존 리본 높이는 유지합니다.
