- native PDF 보기에서 편집기의 Ctrl+A/C/V/D·방향키 처리가 개입하지 않도록 제한했습니다.
- Esc의 그리기 → 선택 → 보기 순서를 통합 화면 회귀 검사와 일치시켰습니다.
