# PDF 보기·수정 (0.3.10)

문서를 열면 같은 화면에 작은 아이콘 리본이 계속 표시됩니다. 상단 순서는 **아이콘 리본 → 문서 탭 → PDF 화면**이며 보기와 편집에서 동일합니다. 별도의 수정 버튼은 없습니다. 아이콘에 마우스를 올리면 기능 이름을 확인할 수 있습니다. 밝은 테마와 WPF `Path`로 직접 그린 벡터 아이콘을 사용합니다.

- **보기(눈)**: 검색·글자 선택·스크롤·인쇄 등 PDF 뷰어 기능을 사용합니다.
- **선택(커서)**: 추가 도형·메모를 선택·이동합니다. 빈 곳에서 드래그하면 영역과 겹치는 항목을 여러 개 선택합니다. 본문 수정은 글자 펼침의 **본문 수정**으로 명시적으로 시작합니다.
- **글자 펼침**: 본문 수정 / 글자 추가를 고릅니다. 리본은 한 줄이며 중복 글자 입력란은 표시하지 않습니다. 글자는 문서 위에서 직접 입력합니다. 추가 글자는 더블클릭, 메모는 클릭해 다시 입력합니다. 메모는 Enter로 줄바꿈, Ctrl+Enter 또는 바깥 클릭으로 적용합니다. 새 메모를 배치하면 자동으로 선택 도구로 돌아갑니다.
- **그리기 펼침**: 선·화살표·사각형·타원·자유곡선을 고르고 문서 위를 드래그합니다.
- **표시 펼침**: 메모·형광펜·밑줄·취소선을 사용합니다. 밑줄과 취소선은 드래그 시작 높이에 수평선을 그리는 영역 표시입니다.
- **도장**: PNG/JPG 이미지를 선택해 위치를 클릭합니다. 투명 PNG를 지원합니다.
- **원형 색상 버튼**: 팔레트·선 미리보기·두께 슬라이더가 펼쳐집니다. 다음 그리기에 쓰이며 선택한 추가 항목에도 반영합니다. 본문 교체의 색상은 내용 적용 시 반영합니다.
- **⋯ 더보기**: 글꼴·정렬·점선·채움, 복제·회전·앞뒤 배치, 실행 취소, 페이지 회전·삭제·순서, 편집 파일 저장·열기를 사용합니다.

## 도구 선택과 Esc

리본에서 도구를 고르면 같은 문서의 편집이 활성화됩니다. **그리기·표시 도구에서 Esc를 누르면 선택 도구로 전환합니다. 마우스로 끌며 그리는 중이라면 그 도형만 취소하고 완성한 항목은 유지합니다. 선택 도구에서 다시 Esc를 누르거나 보기 아이콘을 누르면 수정 내용을 포함한 PDF 보기로 돌아갑니다.** 영역 선택 중 Esc는 영역 선택을 취소하고 이전 선택 상태로 돌아갑니다. 이 과정은 원본 저장이나 수정 내용 삭제가 아닙니다. 수정 상태·실행 취소 기록을 유지하며, 같은 도구를 다시 눌러 이어서 편집할 수 있습니다. 미리보기 PDF는 로컬 캐시에 만들고 동일한 편집 상태의 결과를 재사용합니다. 내용이 영역을 벗어나 PDF를 만들 수 없으면 편집 화면에 오류를 표시하고 작업 상태를 유지합니다.

자체 창 안의 PDF 뷰어 접근성 정보에서 현재 페이지·페이지 폭을 읽어 편집 페이지와 확대율을 연결합니다. 다른 앱은 조회하지 않습니다. 해당 정보가 제공되지 않는 WebView2 버전에서는 마지막 편집 페이지를 유지하므로 리본의 페이지 번호와 **이동**을 사용합니다. 보기에서도 이 공통 페이지 이동을 사용할 수 있습니다.

문서를 바꾸거나 닫을 때 저장하지 않은 수정은 확인합니다. 기본 보기에서는 원래 PDF 뷰어의 검색·인쇄 기능을 유지하고, 편집 중에는 페이지 위의 글자·도형을 조작합니다.

## 항목과 저장

기본 색상은 주황색(`#FF6500`)입니다. Ctrl+클릭은 선택 추가·해제, Shift+클릭은 추가입니다. 드래그 영역에도 Ctrl은 토글, Shift는 추가로 동작합니다. 선택 항목은 함께 이동·삭제·색상 변경할 수 있습니다. 선·화살표는 두 끝점을 끌어 방향과 길이를 바꿉니다. 단순 클릭·미세한 손떨림은 도형으로 생성하지 않습니다. 파란 모서리로 비례 크기 조절, 90도 회전, 맨 앞·맨 뒤, 복제·삭제를 지원합니다. Delete는 선택 항목 삭제, Ctrl+D는 복제, 방향키는 1pt 이동, Shift+방향키는 10pt 이동입니다. Ctrl+A/C/V/Z/Y를 사용할 수 있으며 글자 입력란에서는 일반 텍스트 단축키가 우선합니다. 복사는 현재 편집기 안에서 처리됩니다. 교체 본문을 붙여넣으면 새 글자 상자가 됩니다. 실행 취소는 최근 100개 작업을 보관합니다.

- **저장 / Ctrl+S**: 공유용 새 PDF를 만듭니다. 추가 도형은 PDF 내용으로 합쳐지므로 이 PDF만 다시 열면 원래의 항목 편집 정보는 복원되지 않습니다. 수정본은 새 탭에 열고 원본을 보존합니다.
- **⋯ → 편집 저장**: 원본 PDF 사본, 편집 항목과 도장 이미지를 `.topdf` 파일에 함께 저장합니다. 페이지 순서·회전·글자·도형 속성을 유지하며 계속 편집할 수 있습니다. 원본 사본을 포함하므로 문서와 같은 수준으로 보관하세요.
- **파일 추가 / ⋯ → 편집 열기**: `.topdf`를 열어 작업을 이어갑니다. 저장은 기존 파일을 덮어쓰지 않으므로 새 이름을 지정합니다.

메뉴의 현재 PDF 저장 및 선택 저장에도 현재 문서의 수정 내용을 반영합니다. 편집용 원본 복사본·페이지 이미지·미리보기 임시는 앱의 로컬 캐시에 저장되며 외부로 전송하지 않습니다.

## 범위와 제한

본문은 PDF가 저장한 글자 객체를 바탕으로 **줄 단위**로 교체합니다. 원본 글꼴·실제 글자 크기·기준선·문자 간격을 재사용하며 배경·다른 글자·벡터·이미지를 유지합니다. 같은 길이의 수정은 원래 글자 표시 명령과 변환을 유지한 채 문자 코드만 바꿉니다. 길이가 달라질 때도 원래 글꼴과 변환을 적용하며 글자 크기를 자동 확대·축소하지 않습니다. 주변 공간 안에서 입력 영역을 넓히고 줄바꿈할 수 있지만 Word처럼 문단과 뒤 페이지를 자동 재배치하지 않습니다. 빈 문구 적용은 선택 본문 삭제입니다.

스캔·윤곽선 글자, 잘못된 문자 매핑, 세로·기울어진 글자, 투명도 그룹 등 특수 구조는 직접 본문 수정 대상에서 제외합니다. OCR 텍스트가 있어도 이미지 속 글자가 함께 바뀌지는 않습니다. 개인정보 전체 삭제(리댁션), 전자서명, CAD 원본 객체 편집은 지원하지 않습니다. 이미지 도장은 인증서 기반 서명이 아니며 메모는 Acrobat의 별도 주석이 아닙니다.

암호화 PDF, 입력 양식·서명, 첨부 파일·포트폴리오 PDF는 편집 대상에서 제외합니다. 이 경우 일반 보기는 계속 사용할 수 있습니다. 편집은 최대 200MB·500쪽, 추가 항목 5,000개까지입니다. 새 글자 상자는 맑은 고딕·굴림·바탕을 지원합니다. 기존 본문은 PDF의 내장 글꼴을 우선 재사용합니다. 내장 부분 글꼴에 없는 새 글자는 같은 글꼴이 이 PC에 설치되어 있고 해당 문자를 지원할 때 보완합니다. 같은 글꼴을 사용할 수 없으면 오류를 표시하며 다른 글꼴로 조용히 바꾸지 않습니다.

편집 파일은 형식 버전·원본 SHA-256·경로·항목 수·크기·좌표를 검증하고 PDF 저장 엔진으로 전체 항목을 확인한 후 적용합니다. 외부 이미지 경로와 실행 파일은 불러오지 않습니다.

## 검증

- `PreviewSmoke --unified-ui`: 기본 보기와 간단한 리본, 도구 선택, Esc 후 수정 내용 표시·보존, 같은 도구 재선택, 실행 취소 기록, 현재 페이지 연동, 문서·편집 파일·탭 이동, 단일 창과 원본 보존을 실제 WPF/WebView2에서 검사합니다.
- `PreviewSmoke --inline-edit-ui`, `--drawing-ui`, `--pdf-edit-ui`: 기존 본문 직접 입력·저장·새 탭, 모든 그리기·팔레트·여러 항목 편집·편집 파일 재열기, 페이지 회전·삭제·재정렬을 검사합니다.
- `tests/PdfEdit/test_edit.py`, `test_text_edit.py`, `test_drawing.py`: 합성 PDF로 한글·글꼴·정렬·배경·투명도, 실제 원문 제거와 공유 Form 격리, 회전/CropBox/UserUnit 좌표, 주석·북마크, 원본 해시와 잘못된 입력 거부를 검증합니다. 저장 결과는 독립 PDF 렌더러로 확인합니다.


## 원문 모양 보존과 페이지 보기

기존 본문을 클릭할 때 임의의 맑은 고딕 글자가 원문 위에 겹치지 않습니다. 입력 창은 원래 글자 크기와 위치를 따르고, 글자의 실제 표시는 PDF 렌더러로 유지합니다. 입력 중 미리보기는 짧은 지연 후 갱신되며 저장 결과에도 같은 글꼴·기준선·크기를 적용합니다. 이미 수정한 본문도 더블클릭해 이어서 수정합니다. 길어진 내용이 영역을 벗어나면 자동으로 글자를 줄이지 않고 영역을 넓히거나 내용을 줄이도록 안내합니다. 명시적으로 글꼴·크기를 바꾸는 경우는 별도 서식 변경입니다.

왼쪽 페이지 패널은 기본으로 숨깁니다. 리본의 **페이지 목록** 아이콘으로 열며, 페이지 축소 이미지와 번호, 선택 테두리가 표시됩니다. **×**로 닫을 수 있고 리본 번호 입력·이동은 패널을 닫아도 유지됩니다. 한 페이지 보기에서는 PDF 뷰어의 기존 축소 이미지 패널을 사용합니다.

리본의 **페이지 보기**에서 **한 페이지·두 페이지·세 페이지**를 고릅니다. 두·세 페이지는 가로로 나란히 배치한 렌더링 미리보기이며 여러 줄은 스크롤합니다. 페이지를 클릭해 선택하고 편집 도구를 누르면 해당 페이지를 수정합니다. Esc는 선택한 보기 배치로 돌아갑니다. 한 페이지 보기는 기존 PDF 뷰어의 글자 선택·검색·인쇄를 제공하고, 두·세 페이지 미리보기에서 해당 기능이 필요하면 한 페이지 보기로 전환합니다.

`tests/PdfEdit/test_typography.py`는 축소 변환이 있는 17pt 본문, 원문과 동일한 픽셀의 무수정 재저장, 글자 수정 시 기준선·글꼴·굵기·간격·배경 보존을 독립 렌더러로 확인합니다. `PreviewSmoke --font-views-ui`는 원문 크기 입력·저장·재수정, 기본으로 숨긴 축소 이미지 패널, 패널 열기·닫기, 한·두·세 페이지 전환을 검사합니다.

## 본문 입력 표시와 글꼴

커서·선택 영역은 PDF 글자의 실제 좌표를 사용합니다. 입력 중에는 본문을 지운 페이지 위에 즉시 입력 내용을 표시하고, 잠시 멈추면 PDF 엔진의 정확한 결과로 갱신합니다. 구형 한글 글꼴의 Johab/Unicode 문자표 선택과 비ASCII PostScript 이름을 메모리 내에서 정규화하며 설치된 원본 글꼴 파일은 변경하지 않습니다. 본문 수정은 여전히 글꼴과 PDF 구조에 따른 제한이 있으므로 선·도형·메모 기능을 우선 권장합니다.
