# PDF 수정 (0.3.2)

PDF를 열거나 문서 변환을 완료한 뒤 상단 **수정**을 누릅니다. 같은 본 화면에서 작업하고 **새 PDF로 저장**하면 수정본이 앱의 새 탭에 열립니다. 원본 파일과 기존 파일을 덮어쓰지 않습니다. **보기로**를 누르면 일반 PDF 미리보기로 돌아갑니다.

- **본문** (기본 도구): 기존 문장을 클릭하면 그 위치에 입력창이 나타납니다. 직접 입력하고 Enter 또는 `내용 적용`으로 적용합니다. Shift+Enter는 줄바꿈, Esc는 선택 취소입니다. 원래 글자 객체를 제거한 뒤 새 문구를 넣으며, 투명 배경·벡터·이미지를 유지합니다. 주변 공간 안에서 입력 영역을 넓히고 필요하면 줄바꿈합니다. 빈 문구 적용은 선택 본문 삭제입니다.
- **글자 / 메모**: 도구를 고르고 내용을 입력한 뒤 페이지를 클릭합니다. 메모는 노란 배경의 보이는 내용으로 저장됩니다.
- **도장**: `도장 선택`으로 PNG/JPG 이미지를 고른 뒤 페이지를 클릭합니다. 투명 PNG를 지원합니다.
- **선택**: 추가한 항목을 클릭하고 끌어 위치를 옮깁니다. 내용을 고친 뒤 `내용 적용`, 크기 `− / +`, `항목 삭제`를 사용할 수 있습니다.
- 왼쪽 번호 입력과 `이동`으로 원하는 페이지로 바로 이동합니다. 페이지를 선택하고 회전·삭제·앞으로·뒤로 이동합니다. 마지막 한 페이지는 삭제할 수 없습니다.
- `되돌리기 / 다시 실행`, Ctrl+Z / Ctrl+Y를 지원합니다. 텍스트 입력 중에는 입력창의 기본 되돌리기가 동작합니다. Ctrl+S는 새 파일 저장 창을 엽니다.

본문은 PDF가 저장한 글자 객체를 바탕으로 **줄 단위**로 선택·교체합니다. Word처럼 문단과 뒤 페이지를 자동으로 재배치하지 않으므로 긴 문구는 공간과 줄바꿈을 확인하세요. 수정 문구는 맑은 고딕으로 저장되어 기존 글꼴과 모양이 달라질 수 있습니다. 스캔·윤곽선 글자, 잘못된 문자 매핑, 세로·기울어진 글자, 투명도 그룹 등 특수 구조는 직접 본문 수정 대상에서 제외합니다. OCR 텍스트가 있다고 해서 이미지 속 글자도 함께 바뀌는 것은 아닙니다. 개인정보 전체 삭제(리댁션)와 전자서명은 지원하지 않습니다. 이미지 도장은 인증서 기반 서명이 아니며 메모는 Acrobat의 별도 주석 항목이 아닙니다. 저장 후 다시 열면 추가 항목은 PDF 내용에 합쳐져 개별 편집 이력이 남지 않습니다.

암호화 PDF, 입력 양식·서명이 있는 PDF, 첨부 파일·포트폴리오 PDF는 편집 대상에서 제외합니다. 최대 200MB·500쪽이며 추가 항목은 5,000개까지입니다. 한글 글자는 Windows 맑은 고딕 글꼴을 PDF에 포함합니다. 편집용 원본 복사본·페이지 이미지·수정본 임시는 앱의 로컬 캐시에 저장되며 외부로 전송하지 않습니다.

## 검증

`tests/PdfEdit/test_edit.py`는 자체 제작 PDF로 한글·메모·투명 도장, CropBox·UserUnit·회전 좌표, 공유 내용 스트림의 페이지 격리, 페이지 삭제·재정렬, 기존 주석·북마크 유지, 원본 해시와 덮어쓰기 거부를 검사합니다. PyMuPDF와 Poppler로 저장 결과를 렌더링해 확인합니다.

`tests/PdfEdit/test_text_edit.py`는 번들 Python으로 실행하며 자체 PDF를 생성합니다. 한글 본문 교체·실제 원문 제거·공유/중첩 Form 격리·나머지 본문과 배경 보존·재선택·네 방향 회전·CropBox·UserUnit·잘못된 선택 거부를 검증합니다. 번들 PDFium의 중첩 Form 저장 제약을 피하기 위해 일반 Form은 변환 행렬과 BBox 클리핑을 유지하며 페이지에 펼친 뒤 수정하고, 투명도 그룹은 제외합니다. 저장 전 수정하지 않은 글자 수 검사를 수행합니다.

`tests/PreviewSmoke --inline-edit-ui <자체 제작 3쪽 텍스트 PDF>`는 본 화면 선택·직접 입력·적용·되돌리기·새 파일 저장·새 탭 복귀를 검증합니다.

`tests/PreviewSmoke --pdf-edit-ui <자체 제작 3쪽 PDF>`는 실제 WPF 편집 창의 미리보기·추가·회전·되돌리기·삭제·재정렬·저장·재검사를 수행합니다.
