# 스마트 문서 기능 0.3.0

화면 위 **스마트** 버튼을 누르면 작은 패널이 열립니다. 기존 파일 메뉴·전체 미리보기·선택 저장을 유지합니다.

## 1. 품질 점검과 HWPX

변환 완료 후 또는 PDF를 열면 자동 점검합니다. 빈 페이지 추정, 검색할 문자가 적은 페이지, 깨진 문자, 원본 숫자가 PDF에서 확인되지 않는 경우, 설치 목록에서 찾지 못한 글꼴, CAD 외부 참조 확인 사항을 표시합니다. HWP는 rhwp 원본 텍스트와 페이지 수, HWPX/DOCX/XLS/XLSX는 지원하는 원본 텍스트·숫자를 대조합니다.

점검은 **누락 의심을 찾는 보조 기능**입니다. 글꼴 이름 별칭·수식 표시·숫자 형식에 따라 경고가 생길 수 있고, 경고가 없다고 완전 일치를 보장하지 않습니다. 암호 PDF는 점검을 중단하며 200MB/500쪽 및 검색 텍스트 길이 제한이 있습니다.

HWP를 HWPX로 내보낸 9쪽 시험 파일에서 PDF 변환·내부 미리보기를 확인했습니다. 다른 작성 프로그램의 다양한 HWPX를 검증한 것으로 확대하지 않습니다. 한글 모노스페이스 대체 글꼴을 Windows 맑은 고딕으로 명시했습니다.

## 2. OCR

**스마트 → 점검 → 스캔 문자 읽기 (OCR)**에서 한국어·영어를 인식합니다. 글자가 충분한 페이지는 재인식하지 않고, 스캔 페이지에는 보이지 않는 문자층을 원래 페이지 위에 합칩니다. 원본은 보존하고 새 PDF를 만듭니다. 저장 버튼으로 결과를 내보내세요.

Tesseract 엔진·kor/eng 모델·PDFium 렌더러를 포함합니다. 별도의 Office/OCR 프로그램 설치 없이 동작합니다. 현재 200MB/100쪽 및 페이지 이미지 크기 제한이 있으며 손글씨·낮은 해상도·복잡한 표의 정확도는 보장하지 않습니다. 한글 폴더와 엔진 경로도 시험했습니다.

## 3. 열린 문서 통합 검색

**스마트 → 검색**에서 열린 문서 전체의 추출/OCR 텍스트를 검색합니다. 결과를 두 번 클릭하면 문서와 해당 PDF 페이지로 이동합니다. 최대 300건을 표시하며 OCR 전 스캔 문자는 검색할 수 없습니다. 앱을 닫은 뒤 전체 PC 문서를 검색하는 서비스는 아닙니다.

## 4. 문서 비교

**스마트 → 비교**에서 현재 문서와 다른 열린 문서를 고릅니다. 같은 페이지 위치의 문장 추가·삭제, 금액 변경, 중복 문장 개수와 순서 변화를 표시합니다. 페이지 삽입으로 내용이 밀린 경우 여러 변화가 표시될 수 있습니다. 도형·글꼴·이미지·배치 변화는 비교 대상이 아니므로 화면 확인이 필요합니다.

## 5. 로컬 AI 요약·질문

**스마트 → 요약·질문 → 로컬 모델 → AI 답변**을 사용합니다. 질문을 비우면 주요 근거를 바탕으로 요약합니다. **근거 찾기**는 AI 없이도 동작합니다.

내장 llama.cpp CPU 엔진과 Qwen2.5 0.5B 양자화 모델을 포함합니다. 문서 관련 통신은 이 PC의 127.0.0.1로 한정하고, 내장 서버는 임시 포트·임시 인증키와 `--offline`, `--no-webui`를 사용합니다. 앱 종료 시 앱이 시작한 서버만 종료합니다. API 키 구매가 필요하지 않습니다. 모델을 내려받는 빌드 과정과 WebView2 최초 설치에는 인터넷이 필요할 수 있습니다.

이미 이 PC에 Ollama의 다운로드된 로컬 모델이 있으면 선택할 수도 있습니다. 클라우드 모델은 거부합니다. 모델 응답을 문서 근거 ID·직접 인용 JSON으로 제한하고, 실제 원문에서 인용을 확인하지 못하면 답변을 표시하지 않습니다.

내장 0.5B 모델은 경량 시험용입니다. 문서 전체를 무제한 읽지 않으며 관련 발췌 최대 6개를 사용합니다. 인용이 맞아도 AI의 해석·계산이 틀릴 수 있습니다. 계약·금액·일정은 원문을 확인하세요. 외부 AI 서비스로 문서를 전송하는 기능은 구현하지 않았습니다.

## 6. 폴더 자동 변환

**스마트 → 자동화**에서 서로 분리된 입력/저장 폴더를 선택한 뒤 **감시 시작**을 누릅니다. 시작 후 새로 생기거나 바뀌는 지원 문서를 순차 처리하고 PDF를 저장합니다. 기존 파일은 시작할 때 일괄 처리하지 않습니다. 파일 안정화를 기다리고 같은 내용의 중복 이벤트를 합치며, 변환 중 원본이 바뀌면 저장을 보류합니다. 같은 이름 충돌은 기존 선택 저장 서비스의 번호 추가 규칙을 따릅니다.

하위 폴더는 감시하지 않으며 입력 폴더 안에 출력 폴더를 둘 수 없습니다. 감시 중 폴더 변경은 중지 후 진행합니다. 앱이 열려 있는 동안만 동작하고 시작 프로그램·백그라운드 서비스로 등록하지 않습니다.

- 9쪽 HWPX 변환·미리보기, HWP 원본 텍스트/숫자 점검 확인
- 이미지 PDF의 한국어·영어·금액·날짜 OCR과 한글 출력/엔진 경로 확인
- 빈 페이지·금액 누락 의심, 실제 검색 페이지 근거, 문장/금액/중복 변화 확인
- 실제 폴더 DOCX→PDF 저장, 중복 이벤트 억제와 재귀 출력 경로 거부 확인
